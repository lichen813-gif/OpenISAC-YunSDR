# 2×2 STBC 实时视频接板验证

## 两台电脑与两台 SDR

两台电脑均使用支持 816 载波实时视频的 Studio 0.16 更新版。各自在「设备设置」连接本机 PCIe YunSDR，建议 MTU 7,680。视频占用 CH 0 / CH 1，使用同一射频中心频率。可以使用连接到两端口的有线射频台架和已确认的匹配衰减。

1. 在两端进入「实验室 → OpenISAC 感知 / 视频 → 实时视频」，分别选择「设备发送」和「设备接收」。两端点击「应用视频采样率」，核对采样率为 15.36 MSa/s。
2. 在发送端设备设置中配置 TX LO 和衰减，在接收端配置相同频点的 RX LO 和合适的增益。视频启动独占本机设备，并使用连续 DMA 和时间戳。
3. 接收端点「开始设备接收」。发送端选择本地视频或摄像头，保持 1 Mbit/s，点「开始设备发送」。应用内数据报通过 FDM STBC 帧的 CRC 保护和序号重组，接收端从任意完整数据报开始同步，并在获得 H.264 关键帧后显示。
4. 核对发送端已提交包、接收端成功包和序号缺口、IQ 时间戳间断及主机丢块。停止发送后可保持接收端运行，再启动发送以验证新会话重新锁定。接收端的缺口以已收到的相邻序号计算，跨主机端到端时延使用同步时钟或同屏可见计时标记。

已做两工作台、双独立设备接口的模拟 IQ 端到端验证。实物机的射频采样时钟、驱动 DMA 与持续吞吐需接板确认。

## 单台设备有线回环

1. 使用同一台全双工 PCIe YunSDR。将 CH 0、CH 1 的 TX 分别经匹配衰减器连到对应的 RX。将 TX LO 和 RX LO 设为相同频率。
2. 在「实时视频」选择「本机射频回环」，点击「应用视频采样率」。核对 15.36 MSa/s 和 **816 载波**。标称带宽为 12.255 MHz，两路使用 2×2 Alamouti STBC、64‑QAM 和 FDM 导频。
3. 选择本地视频或摄像头，从 1 Mbit/s 开始。记录提交和恢复包数、时间戳间断、主机丢块和显示延迟 P95。需要连续检查时可勾选循环播放。
4. 1 Mbit/s 稳定后，以 1.5 和 2 Mbit/s 重复检查。每个数据报占 5 个正式帧。接收端按 CRC 和数据报序号重组。

同一工作台的「本机仿真回环」也通过 816 载波正式帧处理 IQ。可用 README 中的命令生成仿真基准。仿真结果与真实 DMA、时钟及射频链路的指标分别验收。
