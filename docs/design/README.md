# Design Documentation / 设计文档

[中文](#中文) | [English](#english)

## 中文

本目录集中收录 OpenISAC-YunSDR 首发版本的总体设计与 PHY 扩展设计：

- [OpenISAC 设计分析](OpenISAC_设计分析.md)：系统定位、总体架构、通信与感知流程分析。
- [OpenISAC 高阶调制与 MIMO 扩展设计](OpenISAC_高阶调制与MIMO扩展设计.md)：高阶 QAM、MIMO、链路自适应及工程实现方案。

项目根目录还包含当前实现路线、验证记录与 Windows 使用说明；完整的中英文手册源码位于 `site/src/content/docs/`，构建后的静态文档位于 `docs/`。

## English

This directory collects the system-level and PHY-extension design documents included in the first OpenISAC-YunSDR release:

- [OpenISAC Design Analysis (Chinese)](OpenISAC_设计分析.md): project scope, system architecture, and communication/sensing pipeline analysis.
- [Higher-Order Modulation and MIMO Extension Design (Chinese)](OpenISAC_高阶调制与MIMO扩展设计.md): higher-order QAM, MIMO, link adaptation, and implementation planning.

The repository root also contains current implementation roadmaps, validation notes, and Windows usage guides. Full English and Chinese manual sources are under `site/src/content/docs/`, while the generated static documentation is under `docs/`.
